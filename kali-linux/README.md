## Kali / WSL

You **must clone the GitHub repo first**. `cd kali-linux` from home fails because that folder is not in `~`.

```bash
git clone https://github.com/Infinity-X202/infinityx-osint-lab.git
cd infinityx-osint-lab/kali-linux
bash install.sh
infinityx
```

Without install:

```bash
python3 infinityx.py
```
